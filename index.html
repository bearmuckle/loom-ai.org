Why Loom

Agentic work,
on your terms.

Loom is built around where the work runs, how the interface feels, and who stays in control.

Native by design

A Rust backend and GPUI interface target a fast, cross-platform desktop and browser experience without relying on an Electron shell.

Under the hood · 2 details

01 / One UI, multiple targets

A full GPUI client across desktop and browser.

Loom builds its interface with GPUI and shares its core views, state, and interactions across native desktop and browser WASM. The browser is a first-class client, not a reduced chat window.

02 / UI and execution, separated

Start local. Connect remote when you need to.

Run Loom natively and its host is a worker out of the box—no separate node to set up. Add external workers when you want agents to run beside other repositories or services. The browser client has no local worker, so it connects to a separately running Loom backend. Sessions keep running if the client disconnects.
